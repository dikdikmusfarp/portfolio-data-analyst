🤖 LLM-Powered

PT Kaldu Sari Nabati Indonesia

RKI KPI Ops

The evolution of three prior projects unified into one QSR operations intelligence platform. Every metric and KPI for quick-serve restaurant operations lives here. What makes it different is the LLM integration powered by LM Studio, where the model analyzes per-metric performance comparisons across outlets and time periods, then generates contextual insight narratives. The full automated pipeline runs as follows:

  1. 1. SQL pulls the latest performance data from Redshift
  2. 2. Data is packaged with a structured prompt and sent to the LLM for per-metric comparison analysis
  3. 3. LLM output (insight text) is saved back to Redshift
  4. 4. A second LLM call receives the insights and builds a styled HTML report
  5. 5. The HTML is stored back in Redshift and rendered inside the Power BI dashboard
  6. 6. Power BI is triggered to refresh so the latest AI content appears
  7. 7. Dashboard is exported to PDF and distributed to all management levels, from CEO to outlet manager, every morning

PT Kaldu Sari Nabati Indonesia

Sentinel — Profit & Loss

Finance teams traditionally catch cost anomalies too late. By the time someone notices, the numbers have already moved. Sentinel changes that. Built as a collaboration between the Data and Finance teams, it continuously monitors cost elements across the P&L and flags anything that looks off before it compounds. When an anomaly is detected, the LLM generates a context-aware action recommendation on the spot, so the Finance team doesn't just see a red number. They get a starting point for what to do about it.

  • → Automated anomaly detection across all cost elements in the P&L
  • → LLM generates specific, data-grounded action recommendations per anomaly
  • → Early warning system with visual cost element alerts accessible directly by the Finance team
  • → Designed in close collaboration with Finance, built around how they actually work, not how data teams assume they work
